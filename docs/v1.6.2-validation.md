# v1.6.2 保守リリースの範囲と検証

2026-10-19、Windows / Python 3.11.9。基準はローカルタグ `v1.6.1`、候補は `dev` の既存修正を含む作業ツリー。リリース候補として検証し、公開準備で変更履歴の日付を2026-10-19に確定した。

## 出荷範囲

- 子・孫テーブルへの暗号化、SQL検証設定の継承。
- 引用形式を含むSQL関数制限と、標準 `re` フックの危険な反復パターン検出。
- 即時保存の `batch_update_partial()` の検証からコミットまでの共有ロック。
- self-hosted RPI実行を信頼されたmain push・mainの手動実行へ限定。
- 旧平文の子テーブルの移行手順、READMEの公開済み機能案内、ビルド依存の下限修正。

JSON索引、FTS、状態遷移、ソフトデリート、新たな保存方式は今回の対象に含めない。暗号化や各保存モードとの契約を設計してから機能版で扱う。

## v1.6.1との性能比較

[10負荷の結果](benchmarks/2026-10-19-v162.md) / [生データ](benchmarks/2026-10-19-v162.json)。同じPython・依存関係を使い、v1.6.1タグのソースと候補を各7回AB/BA交互に実行した。各試料は新しいプロセス・実ファイルDBを使い、保存値と整合性を検証した。初回に全体pytestと並走した未完了測定は中断し、保存していない。掲載結果は全体pytest・ビルド・wheel試験の終了後に取り直したもの。

通常・キャッシュ済み・混在一括読取り、非同期一括読取り、自動整合性読取り、実ファイル更新、分割読取り、暗号化分割読取り、v2永続化の10負荷を測定した。候補/旧版の同じ繰返し同士の時間比率中央値は0.959〜1.052。分割読取りの追加Python割当ピークは両版とも502932 bytesだった。これはRSSやSQLiteのネイティブメモリではない。

暗号化分割読取りは初回比率1.052、範囲0.890〜1.482だったため、[同負荷だけを15回再測定](benchmarks/2026-10-19-v162-encrypted.md)した（[生データ](benchmarks/2026-10-19-v162-encrypted.json)）。再測定は比率0.947、範囲0.786〜1.167。増減の方向が安定せず、この環境では再現性のある速度低下を確認していない。高速化の根拠とも扱わない。両測定の生データを残した。

この比較は代表的な10負荷のみで、SQL関数解析やフック付き部分更新の専用性能試験ではない。全環境・全APIでの性能維持は保証しない。比率の中央値と中央値同士の比は一致しない場合があり、記載範囲は観測範囲であって信頼区間ではない。

## 移行の検証と保証範囲

AES-GCM・ChaCha20・Fernetそれぞれで、暗号化された親と旧平文の子を持つDBを作成した。検証済みバックアップと作業用コピーを作り、子だけを直接開いて値を読み、暗号化設定で書き直した。親の復号、子の全キー・値と件数、保存列のBLOB化、バックアップの元値保持を確認した。

移行はアプリの書き込みを停止して作業用コピーで行う。既存平文の自動変換、元ファイル・WAL・空きページ・バックアップの平文消去は保証しない。[日本語の手順](site/operations.md) / [English procedure](site/en/operations.md)。

部分更新のロック保証は同一インスタンス・共有接続内に限る。独立接続・別プロセス・v2の保存待ち書き込みの厳密な一意性は追加しない。標準 `re` の構造検査は保守的な拒否であり、すべてのパターンの線形時間を保証しない。

## 公開前に残る確認

公開作業中にmainのOSV actionがv2.7.0へ進み、差分スキャンが旧引数 `--skip-git` を拒否して停止した。mainの更新を取り込み、push・PR両方の引数からこのフラグを削除した。OSV v2はルートgitディレクトリを既定でスキップするため、スキャン対象の依存ファイルは除外していない。根拠: [OSV migration guide](https://google.github.io/osv-scanner/migration-guide.html)。

- 対象コミットを確定後、リモートmainとの差分を再確認して対象変更だけを取り込む。ローカルmainや追跡refを最新と仮定しない。
- GitHub Actionsの対象OS/Python試験、セキュリティ関連CIを確認する。今回のローカル実行をリモートCIやRPI実機での成功と扱わない。
- 公開日を確定して変更履歴へ反映し、最終配布物を作る。現在の候補配布物は `release-check-dist/v1.6.2/`。
- 過去のセキュリティスキャンの完了状態はこの作業では更新していない。修正試験の成功はスキャン完了の証明ではない。

ローカル候補の検証完了時点ではcommit・push・merge・タグ作成・公開は未実施。2026-10-19にユーザーからcommit・push・リモートCI確認・v1.6.2公開の指示を受け、リリース作業へ進める。リモートCIと公開結果はPR・Actions・リリースの記録を参照する。
